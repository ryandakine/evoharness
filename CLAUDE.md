# Claude Code — evoharness

Read `AGENTS.md` for swarm usage.

When the user wants a **second opinion, committee review, debate, plan critique,
or tool-using audit**, load the `evoharness-swarm` skill
(`.claude/skills/evoharness-swarm/SKILL.md`) and run `bin/swarm` rather than
spawning unstructured sub-agents for that job.

Do not use swarms for ordinary implement/fix/refactor loops.
